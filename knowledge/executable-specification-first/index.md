# Executable Specification First (ES-First)

Development process principle for agent engineering: every implementation or change must be preceded by an Executable Specification that defines pass/fail, verified failing before the fix and passing after.

| Concept | Type | Description |
|---------|------|-------------|
| [ES-First Principle](es-first-principle.md) | Principle | Core principle: write test, verify fail, implement, verify pass |
| [ES Implementation Patterns](es-implementation-patterns.md) | Pattern | Three patterns for executable specifications: deterministic, SDM-hybrid, benchmark |
